# menup — موقع محل برجر، مكة المكرمة

موقع صفحة واحدة بالعربية، اتجاه من اليمين لليسار، بمشهد افتتاحي يبني البرجر طبقة طبقة مع السحب.

## التشغيل محلياً
```
cd site
python3 -m http.server 8099
```
ثم افتح `http://127.0.0.1:8099`.

الفتح بالنقر المزدوج على `index.html` يعرض البرجر ثابتاً بدون رحلة السحب، وهذا متوقع.

## تغيير بيانات المحل
كل البيانات في كائن `SHOP` أعلى `site/assets/app.js`: الاسم، العنوان، الأوقات، الجوال، رقم واتساب، وحسابات التواصل.
الأسعار وأسماء الأصناف داخل قسم المنيو في `site/index.html`.

## بيانات مؤقتة تحتاج استبدال
- رقم الجوال ورقم واتساب (`SHOP.phone` و `SHOP.whatsapp`)
- روابط الانستقرام وتيك توك
- العنوان الدقيق وأوقات العمل
- الأسعار
- الآراء في قسم «الناس تقول»

## البنية
لا يوجد بناء ولا حزم. HTML و CSS و JavaScript عادي، والخطوط مستضافة مع الموقع.
